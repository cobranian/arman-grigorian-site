# Arman Grigorian : maquettes de site

Trois propositions de site pour le pianiste Arman Grigorian, à montrer avant de construire le vrai site.

En ligne : https://cobranian.github.io/arman-grigorian-site/

| Dossier | Maquette |
|---|---|
| `1-epure/` | Épuré, inspiré de jcdijoux.com |
| `2-saison/` | Saison, inspiré de musiciensdulouvre.fr |
| `3-nuit/` | Scène de nuit, direction nouvelle |

- Pages statiques (HTML/CSS en ligne), aucune installation. Pour les voir en local : `python -m http.server`, puis ouvrir http://localhost:8000/
- Contenu et directions graphiques : `docs/brief.md`
- Toutes les pages sont en `noindex` : ce sont des maquettes.
- Les contenus inventés (concerts à venir, etc.) portent la mention « exemple ».
